==================================================
           黑板小喇叭 v3.0 (Cloudflare 原生版)
==================================================

【系统特色】
1. 100% 纯云端架构：采用 Cloudflare Pages 静态网页 + EMQX Cloud 高性能 MQTT 消息服务。
2. 零本地端口与免穿透：彻底抛弃本地 HTTP 8088 端口与内网穿透工具，不被防火墙拦截，不占端口。
3. 现代毛玻璃微质感：Windows Fluent / macOS 风格半透明卡片，大字号教学大屏适配。
4. 全场景即用即发：教师在操场、走廊、办公室用手机任意网络（4G/5G/校园网）直接发送呼叫。
5. 安全防伪口令：班级编号与教师防伪口令双重匹配，防误触乱播。
6. 双进程防杀看护：若在 Windows 任务管理器中被恶意或误结束进程，守护进程会在 0.5 秒内自动复活自愈并弹出恢复提示。如需正常退出软件，必须在程序主界面点击【退出 🔒】并输入管理员密码！

--------------------------------------------------
【第 1 步：部署手机端控制台 (仅需 1 分钟，免费且永久)】
1. 访问 Cloudflare 控制台：https://dash.cloudflare.com/
2. 点击左侧菜单【Compute (Workers & Pages)】->【Create application】-> 选择【Pages】-> 点击【Upload assets】。
3. 输入您的项目名称（例如: blackboard-notifier），点击【Create project】。
4. 将本目录下的 [cloudflare_pages_deploy.zip] 解压，把里面的 index.html 和 mqtt.min.js 上传。
5. 点击【Deploy site】，部署成功后您将获得专属网址（例如: https://blackboard-notifier.pages.dev）。

--------------------------------------------------
【第 2 步：电脑端运行与绑定】
1. 双击运行 [黑板小喇叭.exe] 或 [启动黑板小喇叭.bat]（程序默认请求管理员权限并在后台静默运行）。
2. 点击右上角【⚙️ 系统设置 🔒】输入默认管理员密码 [888888]。
3. 在【Pages 专属域名】输入框中粘贴您在第 1 步获得的专属网址（如 https://blackboard-notifier.pages.dev）。
4. 系统下方会立即自动生成包含班级编号与防伪口令的二维码。
5. 点击【💾 保存全部配置】。

--------------------------------------------------
【第 3 步：手机扫码即发】
- 教师用手机微信、浏览器扫描电脑端设置界面的二维码即可自动进入控制台并自动填入班级与口令。
- 也可以把该网页添加到手机桌面，随时随地一键呼叫！
- 支持三种模式：【叮咚+语音】、【仅叮咚】、【静音弹窗】。

--------------------------------------------------
【第 4 步：退出与防强杀说明】
- 点击主界面右上角的【×】会默认最小化至系统托盘，不会退出。
- 若需要彻底退出程序，请点击主界面左上角的【退出 🔒】，输入管理员密码（默认 888888）后即可安全退出。
- 若在 Windows 任务管理器中直接点击“结束任务”，守护进程会在 0.5 秒内自动复活本程序，防止被学生或无关人员关闭！
